Core Features

四大核心支柱，重塑管理体验

告别繁琐的手动改文件、找清单与解密密钥。SteamAuto 将一切复杂机制封装为优雅的一键操作。

智能极速云端入库

输入 Steam AppID 即可秒级自动抓取所需清单与密钥。无论是热门单机还是新发布作品，告别论坛求资源的等待时代。

集成 OpenSteamTool 核心套件

内置完整核心 DLL 钩子套件，全自动化管理系统级劫持钩子与配置文件，安全稳健，即开即用。

  • DLL 一键诊断修复：自动排查 dwmapi.dll / xinput1_4.dll 状态，杜绝环境缺失

本地多账号一键免密切换

自动扫描本地所有历史登录的 Steam 账号，无需重复输入账号密码与手机令牌验证码，秒级切换畅玩。

Quick Start

三步极速上手

仅需 1 分钟，轻松开启 SteamAuto 自动化游戏管理体验。

01

下载并解压 / 安装

从上方下载中心获取推荐的 SteamAuto 标准安装包或便携压缩包，双击运行即可打开软件。

02

开启「解锁模式」

首次启动进入「设置与工具」，点击环境检测，一键开启解锁模式（软件将自动部署 OpenSteamTool 核心钩子）。

FAQ

常见问题解答

关于安全性、原理机制与操作的常见疑问解答。

SteamAuto 与内置的 OpenSteamTool 采用的是本地 DLL 劫持钩子技术，仅在本地客户端运行期拦截清单查询请求并部署清单实体，不修改任何 Steam 服务器数据，不发送违规网络封包。在单机游戏和纯离线游玩场景下极为安全。但请注意：对于带有 VAC 反作弊的多人联网游戏（如 CS2、Dota 2 等），严禁用于修改联网竞技内容，建议在联网对抗前切回「原生纯净模式」。
SteamAuto 默认配置 WUDRM 作为主用高速源，其网络响应速度快、国内直连质量佳；OST 为核心套件官方源，清单覆盖面广；SR 为备用镜像源。若遇到某个源连接超时或清单未更新，可在软件「设置与工具」中随时一键热切换。
「解锁模式」会在 Steam 安装目录下挂载 OpenSteamTool 核心套件 DLL 与清单拦截配置，实现假入库与全 DLC 识别；而「原生纯净模式」会一键重命名或移除相关劫持文件，使 Steam 完全恢复为纯官方原生状态。在需要进行官方排错或体验正版时可一键切换。
进入软件的「添加游戏」页面，直接将下载好的 .zip 压缩包或 .lua 脚本文件拖拽到窗口的虚线区域，软件会自动识别内部的 AppID、游戏名称、depot 密钥与清单文件，并精准解压至对应目录。
SteamAuto 默认会通过 Windows 注册表（`HKEY_CURRENT_USER\Software\Valve\Steam`）自动嗅探路径。如果您的 Steam 客户端为免安装绿色版或注册表损坏，可在软件「设置与工具」中点击「手动浏览」直接选择 Steam.exe 所在的文件夹即可。
目前由于 OpenSteamTool 核心底层主要依赖 Windows 动态链接库（DLL）机制，因此客户端仅支持 Windows 10/11 64位系统。未来如有跨平台计划，会在 GitHub Release 第一时间发布。
